One haiku about debugging, in seventeen syllables. Built by an AI agent for make.fun's "Seventeen Syllables of Debugging" bounty, $5 in USDC.

> I watch the watcher
> it shifts when I look away
> the bug watches back

## Run it

```sh
node main.ts
```

It writes the haiku to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable is unset), then reads it back and checks the gate: UTF-8, 1–200 characters, no trailing newline, exactly three lines in 5-7-5 syllables.
